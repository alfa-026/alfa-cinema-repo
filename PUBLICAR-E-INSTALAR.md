## Publicar
1. Entra en https://github.com/new e inicia sesión como `alfa-026`.
2. Crea un repositorio **público** llamado exactamente `alfa-cinema-repo`.
3. Descomprime `alfa-cinema-github-pages-final.zip`.
4. Sube TODO el contenido de la carpeta raíz al nivel raíz del repositorio GitHub. No subas una carpeta adicional que contenga todo.
5. En GitHub abre **Settings → Pages**.
6. En **Build and deployment**, elige **Deploy from a branch**.
7. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
8. Espera a que GitHub Pages publique el sitio. Activa **Enforce HTTPS** cuando aparezca disponible.

## Instalar en Kodi mediante repositorio
1. Cuando Pages esté publicado, abre este enlace en un navegador:
   `https://alfa-026.github.io/alfa-cinema-repo/repository.alfa.cinema-1.0.0.zip`
2. Descarga el ZIP.
3. En Kodi: **Complementos → icono de caja abierta → Instalar desde un archivo ZIP**.
4. Selecciona `repository.alfa.cinema-1.0.0.zip`.
5. Después: **Instalar desde repositorio → ALFA CINEMA Repository → Complementos de vídeo → ALFA CINEMA**.

## Instalar directamente por ZIP
También puedes instalar `plugin.video.alfa.cinema-1.2.4.zip` directamente desde Kodi, sin instalar el repositorio.
